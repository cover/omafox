# Privacy

Omafox does not collect, transmit, sell, or share personal or technical data.
It makes no network requests.

The Firefox/Zen extension receives the current Omarchy theme name and color
palette from the locally installed Omafox native messaging host. This data is
used only to apply the browser theme and is retained locally in the browser's
extension storage. The native host reads the current theme state from the
user's local filesystem.

For native Zen Browser installations, `omafox setup` also writes a packaged
stylesheet and small, clearly marked configuration blocks into each detected
local Zen profile. It does not read or transmit browsing history, bookmarks,
cookies, page contents, or other browser data. No data leaves the user's
device.
